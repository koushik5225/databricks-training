# databricks-training
This repository documents my learning journey in data engineering, covering concepts from fundamentals to real-world implementations. It includes hands-on projects, practice exercises, and notes focused on building practical skills and industry-ready solutions.

#week1 , #day1

This repository contains MySQL practice queries covering basic to intermediate SQL concepts.
It includes joins, subqueries, aggregate functions, grouping, and filtering operations.
The queries are designed using Employee, Department, and Project tables for hands-on practice and learning.

#week1 , #day2
This SQL project demonstrates various database operations using an Employees table, including filtering, sorting, grouping, aggregation, and pattern matching queries. It covers important SQL concepts like WHERE, GROUP BY, HAVING, ORDER BY, LIMIT, DISTINCT, IN, BETWEEN, and LIKE.
